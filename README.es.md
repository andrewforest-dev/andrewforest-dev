### Inventory Pro — Sistema de gestión de inventarios

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)
![Pruebas](https://img.shields.io/badge/Pruebas-54_Aprobadas-brightgreen)
[![CI](https://github.com/andrewforest-dev/inventory-management-system/actions/workflows/javascript-validation.yml/badge.svg?branch=main)](https://github.com/andrewforest-dev/inventory-management-system/actions)

Aplicación web de gestión de inventarios diseñada para ayudar a pequeños negocios a administrar productos, existencias e información comercial.

**Funcionalidades principales:**

- Operaciones CRUD completas.
- Arquitectura modular de software.
- Dashboard con estadísticas dinámicas.
- Búsqueda y filtrado de productos.
- Persistencia de datos mediante LocalStorage.
- Validación de productos.
- Prevención de SKU duplicados.
- Cálculo del valor del inventario.
- Exportación de información a CSV.
- Mitigación de inyección de fórmulas en CSV.
- Interfaz adaptable a diferentes dispositivos.
- 54 pruebas unitarias automatizadas aprobadas.
- Integración continua con GitHub Actions.
- Validación en Node.js 22 y 24.

**Tecnologías:** HTML5, CSS3, JavaScript y Node.js para pruebas automatizadas.

**Estado:** Prototipo frontend con almacenamiento local en el navegador.
